Auto МФГ — графический установщик  v1.2
=======================================

Что это
-------
Программа копирует рядом с игровым EXE:

  version.dll     (можно поставить под другим именем)
  dlssg_sm86.ini

Подходят и Unreal Engine, и другие игры (Unity, REDengine и т.д.).
Мод нужно класть в папку того EXE, который реально запускает рендер.

Как запустить
-------------
1. Нужен Python 3 (https://www.python.org/downloads/).
   При установке включите «Add python.exe to PATH».
2. Дважды щёлкните «Запустить.bat»
   или выполните:  python auto_mfg_gui.py

Как пользоваться
----------------
1. «Папка…» — каталог игры или Steam\steamapps\common
   либо «Указать EXE…» — сразу выбрать игровой exe.
2. Режим поиска:
   • Любые игры — UE + Unity + папки с DLSS + крупные .exe
   • Только Unreal — *-Win64-Shipping.exe
   • Все .exe — широкий поиск без служебных установщиков
3. Если игра не подхватывает version.dll, смените
   «Имя прокси-DLL» на winmm / dxgi / dbghelp / dinput8 / winhttp.
4. Если в меню игры нет пункта генерации кадров —
   включите «Игра без пункта генерации кадров» и выберите 2× / 3× / 4×.
   Установщик запишет принудительный ini (ForceMultiplier).
5. «Установить мод» или «Удалить мод».
   «В эту папку без поиска» — копирует файлы прямо в указанный каталог.

Игры без переключателя
----------------------
Галочка помогает, когда пункт скрыт или серый, но игра уже умеет
DLSS-G / Streamline.

Этот пакет сам НЕ добавляет генерацию в игры, где DLSS-G нет вообще.
Для таких тайтлов положите в папку extras\ дополнительные файлы
(например OptiScaler) — установщик скопирует их вместе с модом.

Важно
-----
- version.dll и dlssg_sm86.ini должны лежать рядом со скриптом.
- Если в папке игры уже был свой version.dll (или другой прокси),
  программа сохранит его как *.mfgbak и вернёт при удалении.
- После правки ini полностью перезапустите игру.
- Ставьте только ОДИН прокси. Не копируйте сразу несколько имён.
- Не используйте в онлайне, где сторонние DLL запрещены.
- Мод рассчитан на DX12 и игры, которые уже умеют DLSS Frame Generation.

Настройки ini
-------------
Router=SM86          — Ampere и новее; для Turing попробуйте SM75
KernelImage=PTX
HardwareBilinear=0
MaxGeneratedFrames=3 — потолок 2x/3x/4x (1/2/3)
Level=1              — уровень лога
