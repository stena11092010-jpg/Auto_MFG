Папка extras
============

Сюда можно положить дополнительные файлы, которые установщик
скопирует в папку игры вместе с version.dll и ini.

Имеет смысл для игр БЕЗ пункта генерации кадров в меню,
если одной связки version.dll + ini недостаточно.

Примеры (класть самостоятельно, в этот архив они не входят):
- файлы OptiScaler (dxgi.dll / OptiScaler.ini и т.п.)
- другие разрешённые сопроводительные DLL той же сборки мода

Не кладите сразу несколько прокси с разными именами
(version + dxgi + winmm) — игра должна грузить только один вход.

Подпапки сохраняются. При удалении мода установщик снимет
только то, что сам сюда скопировал, и вернёт .mfgbak, если был.
